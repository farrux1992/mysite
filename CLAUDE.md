# Farrux Zuvayitov — shaxsiy sayt

## Loyiha
- Farrux Zuvayitovning bir sahifali vizitka sayti. Farrux marketing, IT va biznes o'sishi bo'yicha mutaxassis.
- Auditoriya: biznes egalari. Sayt asosan telefondan ochiladi.
- Fayllar: `index.html` (tuzilish), `style.css` (dizayn), `script.js` (tema + yil), `assets/` (rasmlar).

## Uslub
- Ranglar faqat `style.css` boshidagi tokenlardan olinadi: fon to'q ko'k `#0b1220`, yagona aksent sariq `#f5b544`.
- Ikki tema bor (dark/light). Yangi rang qo'shilsa, ikkala tema blokiga ham yoziladi.
- Shrift: Work Sans. Bo'sh joy ko'p, dizayn toza, ortiqcha bezaksiz.
- Til: o'zbek (lotin). Matnlar "men" nomidan, ishonchli va qisqa ohangda yoziladi.
- Raqam, mijoz, natija yoki logotiplar o'ylab topilmaydi: joyiga namuna matn qo'yiladi va bu haqda aytiladi.

## Texnik chegaralar
- Faqat oddiy HTML, CSS va JS ishlatiladi: framework, kutubxona va build bosqichi yo'q.
- JS minimal bo'ladi. Sayt JS'siz ham to'liq ishlashi kerak.
- Animatsiya yo'q (faqat menyu havolalari uchun silliq aylantirish bundan mustasno). Mobil birinchi: 375px kenglikda sahifa yonga surilmasligi kerak.
- Rasmlar `assets/` papkasida. Rasm bo'lmasa, CSS orqali zaxira (masalan "FZ") ko'rinadi.

## Ish qoidalari
- Qurishdan oldin qisqa reja ko'rsatiladi va tasdiq kutiladi.
- Ish kichik qadamlar bilan qilinadi: bir vaqtda bitta bo'lim.
- Har o'zgarishdan keyin telefon o'lchamida va ikkala temada tekshiriladi.
- Ko'rish uchun mahalliy server Node bilan ishga tushiriladi (Python o'rnatilmagan).
- Javoblar o'zbek tilida, qisqa va aniq bo'ladi.
- Parol, API kalit yoki token hech qachon fayllarga yozilmaydi.
